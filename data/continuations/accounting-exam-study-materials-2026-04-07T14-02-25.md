# COST CLASSIFICATION STUDY GUIDE
*Optimized for Black & White Printing*

## DIRECT vs. INDIRECT COSTS

### DEFINITIONS
**Direct Costs:** Costs that can be easily and accurately traced to a specific cost object
**Indirect Costs:** Costs that cannot be easily traced to a specific cost object

### MANUFACTURING COST CLASSIFICATIONS

| Cost Type | Definition | Examples |
|-----------|------------|----------|
| **Direct Materials** | Raw materials that become part of finished product | Wood for furniture, steel for cars |
| **Direct Labor** | Labor directly involved in production | Assembly workers, machine operators |
| **Manufacturing Overhead** | All other manufacturing costs | Factory rent, utilities, supervisors |

### COST BEHAVIOR PATTERNS

**Fixed Costs:** Remain constant in total regardless of activity level
- Examples: Rent, insurance, salaries
- **Formula:** Total Fixed Cost = Fixed amount per period

**Variable Costs:** Change proportionally with activity level
- Examples: Raw materials, direct labor, sales commissions
- **Formula:** Total Variable Cost = Variable cost per unit × Number of units

**Mixed Costs:** Contain both fixed and variable components
- **Formula:** Total Mixed Cost = Fixed portion + (Variable rate × Activity level)

### PRACTICE PROBLEM

**Scenario:** ABC Manufacturing has the following monthly costs:
- Factory rent: $5,000 (fixed)
- Direct materials: $8 per unit (variable)
- Utilities: $1,200 + $2 per unit (mixed)
- Production: 1,000 units

**Calculate total manufacturing cost:**

**Solution:**
- Fixed costs: $5,000
- Variable costs: $8 × 1,000 = $8,000
- Mixed costs: $1,200 + ($2 × 1,000) = $3,200
- **Total Cost: $16,200**

### OVERHEAD ALLOCATION

**Predetermined Overhead Rate Formula:**
```
Predetermined OH Rate = Estimated Total OH Costs ÷ Estimated Activity Base
```

**Applied Overhead Formula:**
```
Applied OH = Predetermined OH Rate × Actual Activity
```

### CLASSIFICATION DECISION TREE

1. **Can the cost be traced directly to the product?**
   - YES → Direct Cost (Material or Labor)
   - NO → Continue to step 2

2. **Is it a manufacturing cost?**
   - YES → Manufacturing Overhead
   - NO → Continue to step 3

3. **Does it support sales activities?**
   - YES → Selling Expense
   - NO → Administrative Expense

### KEY EXAM TIP
Remember the "Traceability Test" - if you can physically follow the cost to the product without estimation, it's direct. If allocation or estimation is required, it's indirect.
