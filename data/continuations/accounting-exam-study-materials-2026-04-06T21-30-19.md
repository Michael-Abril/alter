## ACC2002 Complete Study Guide - Cost Classification Section

### COST CLASSIFICATION FUNDAMENTALS

**PRODUCT vs PERIOD COSTS**
```
PRODUCT COSTS = All manufacturing costs (DM + DL + MOH)
→ Go to inventory until sold
→ Become COGS when sold

PERIOD COSTS = Non-manufacturing (Selling + Admin)
→ Expensed immediately on income statement
```

**DIRECT vs INDIRECT PRODUCT COSTS**
```
DIRECT COSTS = Traceable to specific product
• Direct Materials (DM): Wood for table, fabric for shirt
• Direct Labor (DL): Assembly worker wages

INDIRECT COSTS = Shared across products → Manufacturing Overhead (MOH)
• Indirect Materials: Glue, screws, supplies
• Indirect Labor: Supervisor, maintenance crew
• Factory Overhead: Rent, utilities, depreciation
```

**VARIABLE vs FIXED COSTS**
```
VARIABLE = Changes with activity level
• Per unit cost stays constant
• Total cost changes with volume
• Examples: Direct materials, sales commissions

FIXED = Stays constant in total
• Per unit cost changes with volume  
• Total cost stays same within relevant range
• Examples: Factory rent, insurance, salaries
```

**THE COST FLOW PATTERN**
```
Raw Materials → Work in Process → Finished Goods → Cost of Goods Sold
     ↓               ↓               ↓              ↓
  Balance Sheet   Balance Sheet   Balance Sheet   Income Statement
   (Asset)         (Asset)         (Asset)        (Expense)
```

### CLASSIFICATION PRACTICE PROBLEMS

**Problem Type 1: Identify Product vs Period**
```
Company XYZ has these costs:
a) Factory supervisor salary     → PRODUCT (MOH)
b) Sales manager salary         → PERIOD (Selling)
c) Wood for furniture          → PRODUCT (DM)
d) Office supplies             → PERIOD (Admin)
e) Factory utilities           → PRODUCT (MOH)
f) Advertising expense         → PERIOD (Selling)
```

**Problem Type 2: Calculate Total Manufacturing Costs**
```
Given:
- Direct Materials Used: $85,000
- Direct Labor: $120,000  
- Manufacturing Overhead: $95,000

Total Manufacturing Costs = DM + DL + MOH
= $85,000 + $120,000 + $95,000 = $300,000
```

**Problem Type 3: Cost Behavior Analysis**
```
At 1,000 units: Total cost = $15,000
At 1,500 units: Total cost = $20,000

Variable cost per unit = Change in cost ÷ Change in units
= ($20,000 - $15,000) ÷ (1,500 - 1,000) = $5,000 ÷ 500 = $10/unit

Fixed cost = Total cost - (Variable rate × Units)
= $15,000 - ($10 × 1,000) = $5,000
```

### MANUFACTURING COST FLOW EQUATIONS

**Basic Cost Flow:**
```
Beginning Inventory + Purchases/Production - Ending Inventory = Used/Sold

For Raw Materials:
RM Used = RM Beginning + RM Purchases - RM Ending

For Work in Process:  
COGM = WIP Beginning + Total Mfg Costs - WIP Ending

For Finished Goods:
COGS = FG Beginning + COGM - FG Ending
```

**Schedule of Cost of Goods Manufactured (COGM):**
```
Direct Materials Used:
  RM Beginning + Purchases - RM Ending = DM Used

Direct Labor

Manufacturing Overhead:
  Indirect Materials + Indirect Labor + Other MOH

Total Manufacturing Costs = DM Used + DL + MOH

Add: WIP Beginning
Less: WIP Ending
Cost of Goods Manufactured (COGM)
```

### EXAM TRAP ALERTS

⚠️ **TRAP: Period costs in manufacturing**
- Sales commissions are PERIOD costs even in a manufacturing company
- Administrative salaries are PERIOD costs
- Don't put selling/admin costs in COGM

⚠️ **TRAP: Indirect vs Direct materials**  
- If material is traceable to specific product = DIRECT
- If material is shared/too small to trace = INDIRECT (part of MOH)

⚠️ **TRAP: Fixed cost per unit**
- Fixed cost per unit DECREASES as volume increases
- Variable cost per unit stays CONSTANT
- Don't confuse total vs per-unit behavior
